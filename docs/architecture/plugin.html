How vme-insight-plugin works

The plugin adds a vme-insight tab to VME's host, VM, instance and cluster pages, and an optional home-dashboard widget. VME only serves the tab: a frame and a link. The browser then loads the dashboard directly from vme-insight, so the VME manager never connects to vme-insight, and the plugin holds no passwords or data. Tabs match the right object because vme-insight's collector stores VME's own ids.

  • Anonymous Viewer (GRAFANA_ANONYMOUS): read-only, no sign-in inside the frame
  • Embedding allowed (GRAFANA_ALLOW_EMBEDDING)
  • GRAFANA_ROOT_URL = the plugin's Grafana URL, so links stay on one address
  • Dashboards filtered by the VME id in the URL

1An admin opens a host, VM, instance or cluster page in VME.
2The plugin returns the tab (an iframe and a link) and a frame-src policy that lets VME's page show it.
3The browser loads the dashboard itself, from vme-insight over https, e.g. /d/vme-hosts?var-host=42.
4The front end checks the certificate is trusted and the network is allowed, then passes the request to Grafana.
5Grafana, as a read-only anonymous Viewer, queries the stored data for that VME id and draws the dashboard.
