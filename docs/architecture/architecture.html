vme-insight architecture

Performance history, capacity, inventory and lifecycle for HPE Morpheus VM Essentials 9.1+  ·  components, ports and data flow  ·  version 0.4.0
VME estate (customer infrastructure)
vme-insight host · one Docker Compose project
Users, VME UI and internet
VME Manager 9.1+ Morpheus appliance VM: UI, REST API, MySQL, Elasticsearch/OpenSearch, RabbitMQ.
  • REST API on :443, read by a dedicated read-only role
  • /api/servers /api/clusters /api/data-stores
  • /api/health /api/health/alarms /api/activity
  • /api/zones /api/instances /api/networks /api/whoami
  • Hosts the vme-insight-plugin (optional, separate repo)
  • Optional: node_exporter :9100 inside the manager VM
HVM hosts × N Ubuntu · KVM/libvirt HVM clusters with shared datastores (GFS2, NFS) and local storage. Each host runs the Morpheus agent, which reports CPU, memory, storage, network, IOPS and CPU ready to the manager.
  • VMs: with the QEMU guest agent, VME also reports the guest OS and in-guest memory
Optional exporters read-only node_exporter :9100: host CPU, memory, PSI pressure, per-mount filesystems, disks, NICs
libvirt exporter :9177: per-VM CPU, vCPU wait, RSS, disk and network
Installed per host with one command; run as unprivileged users; no apt.
collector core Python Polls the VME API on schedules, stores history and inventory.
  • 60 s metrics: servers, clusters
  • 5 min datastores · health, alarms, activity
  • 15 min clouds, instances, networks, version
  • daily OS lifecycle (endoflife.date)
  • TLS pinned by fingerprint; secrets scrubbed before storing
  • Writes Prometheus target files from inventory; serves vme-info :9105
TimescaleDB core PostgreSQL 16 One SQL store for everything the collector gathers.
  • metrics hypertable: raw samples 90 d, compressed after 7 d
  • metrics_hourly rollups: 2 years
  • Inventory tables + change log (trigger)
  • OS lifecycle, agent currency views
  • Users: vme (collector), grafana_ro (read-only)
Prometheus core Scrapes the optional exporters every 30 s; 90-day retention.
  • Targets discovered from VME inventory (no host list to maintain)
  • Jobs: hvm-node, hvm-libvirt, vme-manager, vme-info
Grafana core 11.5 10 provisioned dashboards, guidance tooltips, CSV export.
  • Data sources: TimescaleDB (SQL), Prometheus (PromQL)
  • Treemap plugin (Grafana Labs, pinned)
  • Own port bound to the Docker host by default
installer optional · Caddy :8097 (HTTP) serves install-exporters.sh, the exporter packages (SHA-256 pinned in the script) and the public certificate. Start only while installing.
https front end optional · Caddy :3443 TLS, reverse proxy to Grafana. Network allowlist (403 otherwise). Certificate: organization CA, public CA, or make-cert.sh host certificate. Enables anonymous read-only viewing for embedding.
Internet services endoflife.date: OS release and end-of-life data (daily, HTTPS)
grafana.com: Treemap plugin, first start only (offline install documented)
Admins and operators Browser to Grafana dashboards; sign in to edit.
On the host: export_csv.py, make-cert.sh, screenshots.py, check_dashboards.py
VME UI + vme-insight-plugin Optional companion plugin (separate repo). Host, VM and cluster tabs embed Grafana dashboards in an iframe (kiosk, anonymous Viewer). The browser loads them directly from the https front end.
Docker volumes db-data · grafana-data · prom-data · prom-targets · https-data

Data flows

1collector → VME API: HTTPS 443, OAuth password grant (or token), read-only role, certificate pinned. 60 s to daily.
2collector → TimescaleDB: SQL; metrics by bulk COPY, inventory by upsert; change log written by trigger.
3collector → endoflife.date: HTTPS, daily, OS release cycles and EOL dates.
4collector → Prometheus: target files from VME inventory; VME names (datastore, VM) on :9105.
5Prometheus → exporters: HTTP 9100 / 9177 on hosts and manager, every 30 s. Optional.
6Grafana → data: SQL as grafana_ro to TimescaleDB; PromQL to Prometheus.
7Browser / VME tabs → https front end → Grafana: TLS 3443, network allowlist. Optional.
8Hosts → installer: one-time HTTP 8097, curl … | sudo bash, packages verified by SHA-256.

Required vs optional

Core: collector, TimescaleDB, Prometheus, Grafana. Every API-based dashboard works with only these and a read-only VME account.

Optional: exporters (kernel-level host, VM and filesystem detail), https front end (TLS, allowlist, embedding), installer, VME plugin.

Internet: lifecycle data and the plugin download. Both can be skipped or mirrored.

Security at a glance

Read-only VME account; http upgraded to https; VME certificate pinned.

Agent API keys, credentials and hashes scrubbed before storage.

Grafana reads as grafana_ro; database and Prometheus not published.

Exporters have no auth: bind to management IP, allow only this host.

Browser trust: prefer an organization CA or a host-only certificate (CA:FALSE).
