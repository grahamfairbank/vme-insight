vme-insight architecture

Performance history, capacity, inventory and lifecycle for HPE Morpheus VM Essentials 9.1+  ·  components, ports and data flow  ·  version 0.7.1
Morpheus estate (your infrastructure)
vme-insight host · Docker Compose · or the QCOW2 appliance
Users, Morpheus UI and internet
Morpheus appliance (manager) 9.1+ The manager VM: UI, REST API, MySQL, Elasticsearch/OpenSearch, RabbitMQ.
  • REST API on :443, read by a dedicated read-only role
  • /api/servers /api/clusters /api/data-stores
  • /api/health /api/health/alarms /api/activity
  • /api/zones /api/instances /api/networks /api/whoami
  • Hosts the vme-insight-plugin (optional, separate repo)
  • Optional: node_exporter :9100 inside the manager VM
HVM hosts × N Ubuntu · KVM/libvirt HVM (HPE Virtual Machine) clusters with shared datastores (GFS2, NFS) and local storage. Each HVM host runs the Morpheus agent, which reports CPU, memory, storage, network, IOPS and CPU ready to the manager.
  • HVM VMs: with the QEMU guest agent, Morpheus also reports the guest OS and in-guest memory
Optional exporters read-only node_exporter :9100: host CPU, memory, PSI pressure, per-mount filesystems, disks, NICs
libvirt exporter :9177: per-VM CPU, vCPU wait, RSS, disk and network
Installed per host with one command; run as unprivileged users; no apt.
collector core Python Polls the Morpheus API on schedules, stores history and inventory. HVM clouds only by default (clouds.hvm_only).
  • 60 s metrics: servers, clusters
  • 5 min datastores · health, alarms, activity
  • 15 min clouds, instances, networks, version
  • daily OS lifecycle (endoflife.date)
  • TLS pinned by fingerprint; secrets scrubbed before storing
  • Writes Prometheus target files from inventory; serves vme-info :9105; reads guest memory (libvirt) back for right-sizing
TimescaleDB core PostgreSQL 16 One SQL store for everything the collector gathers.
  • metrics hypertable: raw samples 90 d, compressed after 7 d
  • metrics_hourly rollups: 2 years
  • Inventory tables + change log (trigger)
  • OS lifecycle, agent currency views
  • Users: vme (collector), grafana_ro (read-only)
  • Appliance: re-tuned at boot when the VM's memory changes (database.memory: auto, a quarter of it)
Prometheus core Scrapes the optional exporters every 30 s; 90-day retention.
  • Targets discovered from Morpheus inventory (no host list to maintain)
  • Jobs: hvm-node, hvm-libvirt, vme-manager, vme-info
Grafana core 11.5 10 provisioned dashboards in HPE colors, guidance tooltips, CSV export.
  • Data sources: TimescaleDB (SQL), Prometheus (PromQL)
  • Treemap plugin (Grafana Labs, pinned)
  • HPE backgrounds: grafana/theme/hpe.css, linked from a generated copy of Grafana's index.html
  • No calls to grafana.com while running
installer optional · Caddy :8097 (HTTP) serves install-exporters.sh, the exporter packages (SHA-256 pinned in the script) and the public certificate. Start only while installing.
https front end optional · Caddy TLS on :443 (appliance, on by default) or :3443 (Docker), reverse proxy to Grafana. Network allowlist (403 otherwise). Certificate: organization CA, public CA, or make-cert.sh host certificate. Needed to embed dashboards in the Morpheus UI.
Internet services all optional endoflife.date: OS release and end-of-life data (collector, daily, HTTPS)
grafana.com: treemap plugin download, first start of a Docker install only (the appliance ships it). Grafana itself makes no grafana.com calls while running: update, plugin-update and news checks, Angular-pattern fetches and plugin preinstall are off, and its grafana.com address points nowhere.
Appliance only: api.github.com daily update notice (can be off); vme-insight-update, when run: GitHub, grafana.com, Docker Hub, PyPI.
NTP, UDP 123 (appliance, systemd-timesyncd): the time_servers setting, else DHCP-provided servers or the Debian pool.
Admins and operators Browser to Grafana dashboards; sign in to edit. On the host: export_csv.py, make-cert.sh, screenshots.py, check_dashboards.py
Morpheus UI + vme-insight-plugin Optional companion plugin (separate repo). Host, VM, instance and cluster tabs embed Grafana dashboards in an iframe (kiosk, anonymous Viewer); the browser loads them directly from the https front end. Plugin 0.1.6 theme, by default: vme-insight-theme.js matches each user's Morpheus theme by adding theme=dark or theme=light to the frame URL.
Docker volumes db-data · grafana-data · prom-data · prom-targets · https-data

Data flows

1collector → Morpheus API: HTTPS 443, OAuth password grant (or token), read-only role, certificate pinned. 60 s to daily.
2collector → TimescaleDB: SQL; metrics by bulk COPY, inventory by upsert; change log written by trigger.
3collector → endoflife.date: HTTPS, daily, OS release cycles and EOL dates.
4collector ↔ Prometheus: target files from Morpheus inventory; Morpheus names (datastore, VM) on :9105; every minute the collector reads each VM's guest memory use (libvirt balloon stats) back with PromQL and stores it.
5Prometheus → exporters: HTTP 9100 / 9177 on HVM hosts and the manager, every 30 s. Optional.
6Grafana → data: SQL as grafana_ro to TimescaleDB; PromQL to Prometheus.
7Browser / Morpheus tabs → https front end → Grafana: TLS 443 (appliance) or 3443 (Docker), network allowlist. Optional.
8HVM hosts → installer: one-time HTTP 8097, curl … | sudo bash, packages verified by SHA-256.
9Grafana → grafana.com: treemap plugin download on the first start of a Docker install only. Nothing while running.

Required vs optional

Core: collector, TimescaleDB, Prometheus, Grafana. Every API-based dashboard works with only these and a read-only Morpheus account.

Optional: exporters (kernel-level host, VM and filesystem detail), https front end (TLS, allowlist, embedding), installer.

Morpheus plugin: optional, separate repo; shows the dashboards inside the Morpheus UI.

Internet: lifecycle data, the treemap download (Docker installs) and appliance updates. None is required; the appliance runs on a closed network.

Morpheus: your Morpheus appliance, HVM hosts and users.

Security at a glance

Read-only Morpheus account; http upgraded to https; Morpheus certificate pinned.

Agent API keys, credentials and hashes scrubbed before storage.

Grafana reads as grafana_ro; database and Prometheus not published.

Grafana makes no calls to grafana.com while running.

Exporters have no auth: bind to management IP, allow only this host.

Browser trust: prefer an organization CA or a host-only certificate (CA:FALSE).
